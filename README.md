# Venca Štamgast

Fiktivní AI postava, která každé ráno u třetího stolu od výčepu komentuje, jak se v noci dařilo
Čechům v NHL. Příspěvky vznikají automaticky z dat, Venca k nim píše hlášky a člověk je schvaluje
jedním komentářem.

- **Ranní pivo:** Češi v NHL přes noc (data z veřejného API NHL).
- Grafika 1080 × 1350, Venca v osmi výrazech podle výsledku.
- Čísla do grafiky dosazuje kód, ne AI. Co v textu nesedí s daty, se ukáže ke kontrole.

Nastavení: [docs/nastaveni.md](docs/nastaveni.md). Pravidla projektu: [CLAUDE.md](CLAUDE.md).
